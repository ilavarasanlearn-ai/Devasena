# Devasena Info Project

An informational static website about **Devasena** — the divine warrior goddess of Hindu mythology, consort of Lord Kartikeya (Murugan/Skanda), and personification of the celestial army.

## Live Preview

Open `index.html` in any modern web browser — no build step required.

## Features

- 🌸 **About** — Who Devasena is and her role in Hindu mythology
- 📜 **Origin & Birth** — Her lineage, connection to Indra, and the story of her union with Kartikeya
- ⚔️ **Divine Attributes** — Beauty, protection, purity, celestial power, grace, and wisdom
- 🏛️ **Worship & Temples** — Major temples and festivals dedicated to her
- 🕉️ **Spiritual Significance** — Symbolic meaning in Shaiva and South Indian traditions
- 🌺 **Gallery of Names & Forms** — Her various names in Sanskrit and Tamil

## Usage

Simply clone the repository and open `index.html`:

```bash
git clone https://github.com/ilavarasanlearn-ai/Devasena.git
cd Devasena
open index.html   # macOS
# or
start index.html  # Windows
# or
xdg-open index.html  # Linux
```
